# Animador Automático 🤖

Robô que cria vídeos de histórias animadas com IA e posta no seu Instagram.

**Não precisa mexer em nada aqui.** Tudo é feito pelo app do Animador Automático:
1. Toque em **Use this template → Create a new repository**, com o nome `animador-automatico` e marque **Public**.
2. Volte pro app e siga os 5 passos da ativação.

Seus vídeos ficam salvos no branch `previas`. Suas chaves ficam guardadas no cofre (Secrets) da sua conta, e só você tem acesso a elas.
